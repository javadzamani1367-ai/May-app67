# تحویل فاز 1a — اسکلت پروژه، تقویم شمسی و parser زمان

## آنچه ساخته شد

| ماژول | نوع | محتوا |
|---|---|---|
| `build-logic` | Gradle | Convention pluginها: `roozban.android.application`، `roozban.android.library`، `roozban.android.compose`، `roozban.android.feature`، `roozban.jvm.library`، `roozban.hilt` |
| `:core:common` | JVM | qualifierهای Dispatcher |
| `:core:calendar` | JVM | `JalaliDate` (الگوریتم Borkowski، بازه‌ی سال ۱ تا ۳۱۷۷)، هفته‌ی شنبه‌محور، ارقام فارسی، نام ماه‌ها و روزها، قمری Umm al-Qura با امکان جابه‌جایی ±روز، قالب‌بندی نسبی («امروز»، «فردا»، «پس‌فردا»، ...) |
| `:core:timeparser` | JVM | parser قاعده‌محور عبارات زمانی فارسی (جزئیات پایین‌تر) |
| `:core:designsystem` | Android | تم Material 3 (روشن و تاریک، رنگ پویا به‌صورت اختیاری)، فونت Vazirmatn، RTL اجباری، آیکن‌ها |
| `:feature:today` | Android | صفحه‌ی امروز: تاریخ شمسی به‌همراه میلادی و قمری، نوار هفته، BottomSheet ثبت سریع با هایلایت زنده |

| `:app` | Android | Hilt، انتخاب زبان fa-IR برای برنامه، Splash، flavorهای `bazaar`، `myket` و `dev`، بدون پشتیبان ابری |

## parser زمان — عبارات پشتیبانی‌شده

- **روز نسبی:** امروز، فردا، پس‌فردا (با نیم‌فاصله، بدون فاصله یا جدا)، پس‌پس‌فردا، دیروز، امشب
- **بخش روز:** صبح، صبح زود، اول صبح، ظهر، بعدازظهر، عصر، غروب، شب، نیمه‌شب (ساعت پیش‌فرض هر کدام قابل تنظیم است)
- **ساعت:**
  - «ساعت ۵»، «۱۷:۳۰»، «۵ و نیم»، «۵ و ربع»، «۵ و ۲۰ دقیقه»، «یه ربع به ۶»، «ده دقیقه به ۸ شب»
  - «۸ صبح»، «۵ عصر»، «۱۲ شب» (به معنی نیمه‌شب)، «امشب ساعت ۲» (یعنی ۰۲:۰۰ بامداد فردا)
- **فاصله از الان:** «دو ساعت دیگه»، «نیم ساعت دیگه»، «یه ربع دیگه»، «یک ساعت و نیم دیگه»، «بعد از ۲ ساعت»، «سه روز بعد»، «یک هفته دیگه»، «یک ماه دیگه» (ماه شمسی)
- **روز هفته:** «شنبه»، «سه‌شنبه‌ی بعد»، «سه‌شنبه‌ی آینده»، «سه‌شنبه هفته‌ی بعد»، «هفته‌ی بعد سه‌شنبه»، «جمعه‌ی این هفته»، «همین شنبه»
- **بازه‌ها:** «آخر هفته»، «هفته‌ی بعد»، «آخر ماه»، «اول ماه بعد»، «ماه آینده»، «وسط ماه»، «دهم ماه»، «آخر سال»، «سال بعد»
- **تاریخ صریح:** «۱۵ آبان»، «پانزدهم آبان»، «۱۵ام آبان»، «بیست و پنجم آذر»، «آخر اسفند»، «وسط آذر»، «۲۰ مهر ۱۴۰۶»، «1405/8/1»، «8/15»
- **تکرار (تبدیل به RRULE):**
  - روزانه: «هر روز»، «روزانه»، «هر روز صبح»، «صبح‌ها»، «یک روز در میان»، «هر دو روز»
  - هفتگی: «هر شنبه و دوشنبه»، «شنبه‌ها»، «روزهای زوج و فرد»، «هر روز کاری»، «هر ۳ هفته»
  - ماهانه و سالانه: «آخر هر ماه»، «اول هر ماه»، «پانزدهم هر ماه»، «هر سال»
  - تکرارهای ماهانه و سالانه با `RSCALE=PERSIAN` بر پایه‌ی ماه شمسی محاسبه می‌شوند.
- **تخمین زمان کار:** «۳۰ دقیقه»، «یک ساعت و نیم»، «۲ ساعت»
- **عادی‌سازی ورودی:** ارقام فارسی، عربی و لاتین. حروف ي و ك. نیم‌فاصله. اعراب و کشیده. شکل‌های محاوره‌ای مثل دیگه، یه، صب، میون و پونزده.
- **خروجی:**
  - `ParseResult`: زمان، تکرار، تخمین، `spans` (موقعیت دقیق در متن اصلی برای هایلایت)، `title` (متن بدون عبارت زمانی) و `confidence`
  - برای عبارات مبهم یا گذشته، `confidence` پایین است. UI از کاربر می‌خواهد زمان را بررسی کند. این همان نقطه‌ای است که در فاز ۴ مدل زبانی کمک خواهد کرد.

**قواعد رفع ابهام:**
- «ساعت ۵» بدون قرینه، نزدیک‌ترین وقوع آینده در بازه‌ی ۷ تا ۲۲ است.
- «X‌ی بعد» یعنی X در هفته‌ی تقویمی بعد.
- عدد تنها («فردا ۵») فقط در بافت روشن ساعت حساب می‌شود. پس «فردا ۳ نان بخر» ساعت ۱۵ ثبت نمی‌شود.

## دستور build

پیش‌نیاز: JDK 21 و Android SDK (API 37). نیازی به نصب Gradle نیست (از wrapper استفاده می‌شود).

```bash
./gradlew test                      # همه‌ی تست‌های واحد
./gradlew :core:timeparser:test     # فقط parser (چند ثانیه)
./gradlew assembleDevDebug          # APK توسعه (شناسه‌ی ir.roozban.app.dev)
./gradlew assembleBazaarDebug       # APK بازار
./gradlew assembleMyketDebug        # APK مایکت
./gradlew installDevDebug           # نصب روی گوشی یا شبیه‌ساز متصل
```

CI (GitHub Actions) در هر push تست‌ها، build هر سه flavor و Lint را اجرا می‌کند و APK نسخه‌ی dev را به‌عنوان artifact منتشر می‌کند.

## محدودیت‌های شناخته‌شده

1. **کارها هنوز ذخیره‌ی دائمی نمی‌شوند.** فهرست صفحه‌ی امروز فقط در همین نشست نگه‌داری می‌شود و روی خود صفحه هم این نکته نوشته شده است. Room، یادآوری و آلارم در فاز 1b اضافه می‌شوند.
2. **parser:**
   - نام ماه‌های میلادی («۱۵ ژانویه») و ماه‌های قمری پشتیبانی نمی‌شوند.
   - «یک روز و نیم دیگه» پشتیبانی نمی‌شود.
   - «ساعت ۵ صبح» بدون روز، اگر گذشته باشد به فردا منتقل می‌شود.
   - «امشب» اگر بعد از ساعت ۲۰ گفته شود، ساعت ۲۰ همان شب را برمی‌گرداند (زمانی در گذشته).
   - اگر در یک جمله دو عبارت زمانی جدا از هم باشد، فقط کامل‌ترینشان استفاده می‌شود.
3. **ترجیحات parser** (ساعت پیش‌فرض صبح، عصر و ...) پیاده‌سازی شده‌اند، اما صفحه‌ی تنظیمات آن‌ها در فاز 1b می‌آید.
4. **تعطیلات رسمی** طبق برنامه در فاز ۲ (نمای تقویم) اضافه می‌شوند.
5. **فونت:** چهار وزن ثابت Vazirmatn حدود ۴۹۰KB حجم دارند. در فاز ۸ زیرمجموعه‌سازی (subsetting) یا فونت متغیر بررسی می‌شود.
6. **محدودیت محیط توسعه:** در محیط ابری من، دسترسی به Google Maven مسدود بود. به همین دلیل ماژول‌های JVM (تقویم و parser با ۲۳۵ تست) را محلی اجرا و تأیید کردم، ولی build ماژول‌های Android فقط روی CI در GitHub Actions تأیید شده است. هنوز روی گوشی واقعی اجرا نشده است.
