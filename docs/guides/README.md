# راهنماهای کاربر

| راهنما | برای |
|---|---|
| [راهنمای اپ کارشناس](expert.md) | کارشناس بازدید: ورود، ثبت گزارش، بازدید شش‌مرحله‌ای، مدارک، وضعیت ارجاع و تأیید، همگام‌سازی، ارجاع‌های من |
| [راهنمای اپ بازرسی میدانی](field.md) | کاربر عملیاتی و همکار: گزارش رمزارز، برق غیرمجاز و سوختگی تجهیزات، آمپرگیری فیدر تابلو و تیربه‌تیر، ترموویژن، نقشه آفلاین، صف ارسال و نتیجه هر مورد |
| [راهنمای مدیر](manager.md) | مدیر: اپ مدیر (اشخاص و کاربری‌ها، تأیید، عملکرد واحدها) و پنل وب (موردهای میدانی، ارجاع، تکراری‌ها، برگه ارجاع، خروجی‌ها) |
| [راهنمای مجری](executor.md) | مجری رمزارز هر ناحیه (اپ «توان‌کاو مجری»)، مجری برق غیرمجاز شهرستان و ستاد: میز پیگیری، ارجاع، هشدارها، تأیید، ارسال، امتیازها |
| [راهنمای پرتال واحدها](units.md) | واحدهای فروش، حراست، حقوقی و برق شهرستان |
| [راهنمای استقرار و نگهداری](deploy.md) | کسی که سرور، اپ‌ها، نقشه و آرشیو را راه می‌اندازد و نگه می‌دارد |

نسخه چاپی (PDF، با قلم وزیرمتن):

```bash
pip install markdown-it-py
python3 tools/guides/build.py out/ [--font-dir پوشه‌ای-با-Vazirmatn] [--chrome مسیر-کروم]
```

راهنماها از روی برچسب‌های واقعی صفحه‌ها نوشته شده‌اند (`strings*.xml` و صفحه‌های PHP). اگر
نام دکمه یا مرحله‌ای عوض شد، راهنمای همان بخش را هم به‌روز کنید.
