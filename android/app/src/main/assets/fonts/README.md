# فونت وزیرمتن

این دو فایل را از https://github.com/rastikerdar/vazirmatn (مجوز SIL OFL) دریافت
و در همین پوشه قرار دهید:

```
Vazirmatn-Regular.ttf
Vazirmatn-Bold.ttf
```

فایل‌ها داخل مخزن نگهداری نمی‌شوند. اگر نباشند، برنامه ساخته و اجرا می‌شود اما
رابط کاربری و PDF از فونت پیش‌فرض دستگاه استفاده می‌کنند
(`AppFonts.isBundled` این حالت را تشخیص می‌دهد).

همین فایل Regular به صورت base64 داخل HTML گزارش جاسازی می‌شود تا خروجی PDF
به فونت نصب‌شده روی دستگاه وابسته نباشد.
